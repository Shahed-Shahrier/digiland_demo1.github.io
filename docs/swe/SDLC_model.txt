The Incremental Model was selected as the most suitable SDLC model for the Digi-Land project. This is because the system contains several distinct but related modules, such as registration and login, land information search, ownership transfer application, document upload, officer review, survey verification, status notification, tracking, and audit history. These features can be developed and delivered in separate increments, making the project easier to manage and test. The model is especially appropriate because Digi-Land is an academic prototype with limited time, limited resources, and possible refinement during development. It also supports early testing and gradual improvement, which is important for handling risks such as unauthorized access, fake documents, and data errors. Therefore, the Incremental Model provides the best balance of structure, flexibility, and practicality for this project.
